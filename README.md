# 🎮 Daily Digital Pulse

> An automated, AI-powered Gaming and Technology News Portal running 100% on autopilot.

---

## 🚀 Features
* **AI-Generated Content:** Integrated with Google Gemini AI to write fresh, high-quality gaming articles.
* **Autopilot Architecture:** Powered by Make.com workflows to fetch RSS feeds and push clean HTML directly to GitHub.
* **Dynamic Dark Theme:** A fully responsive, modern dark-mode layout that auto-fetches new articles instantly using JavaScript.

## 🛠️ Built With
* **Automation:** Make.com
* **AI Engine:** Google Gemini
* **Hosting:** GitHub Pages
* **Frontend:** HTML5, CSS3, JavaScript (Async/Fetch API)
